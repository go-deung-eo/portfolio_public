개인 도구

반복되는 작업은 도구로 만들어 두는 편이다. 아래 세 가지는 공개 저장소로 관리하고 있고, 그중 일부는 다른 사람도 실제로 사용했다.

공개 저장소
도구내용사용
be_vim새 서버 인스턴스에 Neovim 개발 환경 전체를 자동 구성하는 스크립트본인 업무 환경
시간과 정신의 방백준 온라인 저지 풀이용 vim·shell 명령어 모음 (코드 템플릿, Makefile, README 생성)본인 + 동문 4명
IRC_server (feat/epoll)학부 시절 IRC 채팅 서버의 I/O 멀티플렉싱을 poll에서 epoll로 전환개인 프로젝트

be_vim은 서버를 새로 받을 때마다 같은 설정을 반복하지 않으려고 만들었다. Neovim 의존 라이브러리와 plug-in, 언어별 LSP를 설치하고 개인 vimrc, 키 매핑, snippet 설정을 적용하며, 현재 설정을 저장소와 push·pull로 동기화한다.

시간과 정신의 방은 문제 풀이의 준비 작업을 줄이는 스캐폴드다. C, C++, Java, Python용 main 함수와 입출력 코드가 들어간 템플릿, 컴파일·테스트·디버깅 명령이 들어간 Makefile, 풀이 메모용 README.md를 명령 하나로 만든다. 동문 4명이 실제로 쓰면서 준 피드백을 반영해 개선해 왔다.

IRC_server는 Tmax Cloud 수습 기간에 사내 epoll 프레임워크를 분석하며 배운 내용을 학부 시절 프로젝트에 다시 적용한 것이다. poll을 epoll로 바꾸고, 쓰기 가능 이벤트(EPOLLOUT)는 보낼 데이터가 있을 때만 켜고 다 보내면 끄도록 토글해 불필요한 이벤트 통지를 줄였다.

비전공에서 엔지니어로

대학은 늦게 들어갔다. 2014년 공군 전역 후 4년 동안 아르바이트를 병행하며 혼자 수능을 다시 준비했고, 27세에 연세대학교 경제학과에 입학했다. 쉽지 않은 시간이었지만, 한 가지를 오래 붙잡고 가는 방식은 그때 몸에 익었다.

프로그래밍은 경제학과의 데이터마이닝 과목에서 처음 접했다. 이후 컴퓨터과학을 부전공으로 택해 운영체제, 데이터베이스, 컴퓨터 아키텍처, 통신 네트워크를 수강했고, 운영체제는 수강생 130명 중 10등(A-)으로 마쳤다. 재학 중이던 2021년부터 2023년까지는 42 Seoul 과정을 병행했다. 소켓과 I/O 멀티플렉싱을 직접 다루는 IRC 채팅 서버도 학부 시절에 만들었고, 졸업 직후 Tmax Cloud에서 epoll 기반 서버 프레임워크를 맡으며 첫 직무를 시작했다.

공군과 조정부

공군에서는 행정 특기로 복무했고, 참모총장실 비서실에서 비서병으로 일했다.

대학에서는 연세대학교 체육부 조정부에서 활동했고, 2018년 8월부터 1년간 재학생 주장을 맡았다. 주장으로서 합숙 훈련을 기획하고 참여했으며, 2019년 전국대학조정대회 에이트(8+) 종목에서 4위를 기록했다.
